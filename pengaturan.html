Tidak ada perubahan

Masuk

Tempel token GitHub Anda. Token hanya disimpan di peramban perangkat ini dan dipakai untuk menyimpan perubahan ke repo website.

Cara membuat token (sekali saja)
  1. Buka github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Isi nama, misalnya Panel situs Zui, dan pilih masa berlaku (misalnya 1 tahun).
  3. Resource owner: zui-system. Repository access: Only select repositories → zui-system/zui-system.
  4. Permissions → Repository permissions: Contents = Read and write, Actions = Read-only.
  5. Tekan Generate token, salin tokennya, lalu tempel di sini. Token bisa dicabut kapan saja dari halaman yang sama.

Aplikasi

Urutan di sini sama dengan urutan ubin di halaman utama. Aplikasi yang disembunyikan tidak tampil di situs.

Tambah aplikasi

Gambar

Tampil di bagian “Tampilan aplikasi” pada panduan aplikasi. Gambar dikecilkan otomatis. Tampilan PC tampil lebar, tampilan HP berjajar. Gambar yang diunggah langsung ke folder img/ di repo tetap tampil di situs, tetapi tidak muncul di daftar ini.

Video

Satu video per aplikasi. Unggah berkas MP4 atau WebM (paling besar 95 MB), atau tempel tautan YouTube.

Kontak

Dipakai di footer semua halaman, halaman Kontak, Tentang, dan tombol WhatsApp.

Teks halaman utama

Judul besar dan kalimat pembuka di bagian paling atas halaman utama.

Tampilan situs

Berlaku untuk semua halaman. Lihat hasilnya di pratinjau sebelum menerbitkan.

Pratinjau memakai isi situs yang sedang tayang dengan tampilan pilihan Anda.

Terbitkan perubahan

Semua perubahan disimpan sebagai draf di perangkat ini sampai Anda menekan Terbitkan. Setelah itu GitHub menyusun ulang halaman, biasanya 1–3 menit.
