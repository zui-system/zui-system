# Screenshot aplikasi

Taruh screenshot di folder ini dengan nama `<aplikasi>-<nomor>.<jpg|png|webp>`, misalnya `erp-1.jpg`, `erp-2.jpg`.
Kode aplikasi: `erp`, `kontraktor`, `finance`, `jurnal`, `todo`, `studikita`.
Gambar tampil otomatis di bagian "Tampilan aplikasi" pada panduan aplikasinya (urut sesuai nomor) setelah halaman dibangun ulang.
Tampilan PC (mendatar) tampil lebar satu per baris dan bisa diklik untuk ukuran penuh; tampilan HP (tegak) tampil berjajar. Orientasi dikenali otomatis. Saran untuk PC: lebar 1280–1600 px, simpan sebagai JPG atau WebP di bawah 400 KB. Pakai data contoh, bukan data pelanggan.
